# Week 2 Day 1 — JavaScript Fundamentals

This project contains practical JavaScript exercises covering variables, data types, functions, conditionals, arrays, and objects.

## Tasks
![shown output](https://github.com/markcliff6064/week-2-day-1-assignment/blob/12d1a97b6853351684e7f05b34aaf169adf01a1b/index.jpg)
### 1. Classic Functions

Implemented five JavaScript functions:

* `fizzBuzz()` — identifies multiples of 3 and 5.
* `reverseString()` — reverses a string.
* `isPalindrome()` — checks whether a string reads the same forwards and backwards.
* `findLargest()` — finds the largest number in an array.
* `countVowels()` — counts vowels in a string.

### 2. Kenyan County Object

Created county objects containing:

* County name
* Capital
* Population
* Area
* Bordering counties

Functions were added to format county information, population numbers, and borders.

### 3. Matatu Route System

Created a collection of Kenyan matatu routes containing fares and stops.

Implemented functions to:

* Find the cheapest route
* Find routes passing through a specific stop
* Calculate the total fare for a journey using multiple routes

### Bonus

Added `numberToWords()` to convert Kenyan shilling amounts into words.
